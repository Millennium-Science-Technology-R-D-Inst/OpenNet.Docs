# 本地化与文档翻译

OpenNet 使用 [Crowdin](https://crowdin.com/project/opennet/) 协作翻译应用界面文本。欢迎参与翻译和校对。

打开 [OpenNet Crowdin 项目](https://crowdin.com/project/opennet/)，选择语言与资源，并按平台提供的术语和审核流程提交翻译。

本文档目前提供简体中文和英语。发现错字、失效链接或术语不一致时，可在[文档仓库](https://github.com/Millennium-Science-Technology-R-D-Inst/OpenNet.Docs)修改对应页面并提交 pull request。请保留产品名称、API、库名与协议名，避免将路线图内容写成已发布功能。
