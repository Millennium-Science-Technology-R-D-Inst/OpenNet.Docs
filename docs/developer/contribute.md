# 参与贡献

欢迎通过代码、问题反馈和本地化参与 OpenNet。开始前先查看仓库现有 issue、贡献说明与许可证。

在 [OpenNet Issues](https://github.com/hoshiizumiya/OpenNet/issues) 搜索相似问题后再创建 issue，并提供系统与应用版本、CPU 架构、复现步骤和预期结果。提交代码前可先通过 issue 确认改动范围，再按[构建指南](/developer/build)配置环境并验证。请避免提交生成文件、个人配置或意外的子模块指针变化。

文档源码在 [OpenNet.Docs](https://github.com/Millennium-Science-Technology-R-D-Inst/OpenNet.Docs)。应用界面翻译通过 [Crowdin](https://crowdin.com/project/opennet/) 协作。
