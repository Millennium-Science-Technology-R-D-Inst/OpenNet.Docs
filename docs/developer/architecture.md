# 技术架构

OpenNet 是 Windows 原生桌面客户端。README 描述的基础包括 WinUI 3、C++/WinRT，以及 MVVM 相关框架。

主要开源依赖包括 [aria2](https://github.com/aria2/aria2)、[libtorrent](https://github.com/arvidn/libtorrent)、[Boost.Asio](https://github.com/boostorg/asio)、[Boost.Beast](https://github.com/boostorg/beast)、[SQLite](https://github.com/sqlite/sqlite)、[OpenNet.Server](https://github.com/Millennium-Science-Technology-R-D-Inst/OpenNet.Server) 和 [OpenNet.Traversal](https://github.com/Millennium-Science-Technology-R-D-Inst/OpenNet.Traversal)。

依赖会持续变化，以[源仓库清单](https://github.com/hoshiizumiya/OpenNet)与项目文件为准；本页不把路线图能力描述为当前架构保证。
