# 发展路线图

本页整理 OpenNet README 列出的规划方向。路线图可能变化，不构成版本承诺；进展以仓库讨论和发布为准。

README 列出的方向包括自动 NAT 穿透、DHT / PEX / LSD、NAT 检测、远程控制、用户登录与多用户管理，以及扩展 HTTP / HTTPS / FTP 下载能力。

当前 README 列出的功能包括 BitTorrent、HTTP / HTTPS、RSS 订阅与自动下载、集成 WebUI 和网络状态工具。上述路线图项目不应被视为已经发布。
