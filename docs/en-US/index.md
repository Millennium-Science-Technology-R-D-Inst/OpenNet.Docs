## About OpenNet

OpenNet is a native Windows download client built with WinUI 3 and C++/WinRT. It currently supports Windows 11 x64 and ARM64. Windows 10 is outside the support plan.

[About the project](/en-US/project) · [Feature guides](/en-US/features/) · [Browse the source](https://github.com/hoshiizumiya/OpenNet)

## Current features and roadmap

Automatic NAT traversal, DHT / PEX / LSD, remote control, and user login with multi-user management are roadmap items, not current-release claims. See the [full roadmap](/en-US/developer/roadmap).
