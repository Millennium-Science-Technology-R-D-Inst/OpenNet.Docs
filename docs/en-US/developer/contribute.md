# Contributing

Contribute to OpenNet through code, issue reports, and localization. Check existing issues, contribution notes, and the license before starting.

Search [OpenNet Issues](https://github.com/hoshiizumiya/OpenNet/issues) for duplicates. Include system and app versions, CPU architecture, reproduction steps, and expected results. For code changes, agree on the scope through an issue, follow the [build guide](/en-US/developer/build), then validate the change. Avoid generated files, personal settings, and unintended submodule pointer changes.

Documentation source lives in [OpenNet.Docs](https://github.com/Millennium-Science-Technology-R-D-Inst/OpenNet.Docs). App interface translations are coordinated through [Crowdin](https://crowdin.com/project/opennet/).
