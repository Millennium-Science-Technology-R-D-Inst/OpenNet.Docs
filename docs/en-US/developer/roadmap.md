# Roadmap

This page summarizes work listed in the OpenNet README. The roadmap can change and is not a release commitment; check repository discussions and releases for progress.

Listed directions include automatic NAT traversal, DHT / PEX / LSD, NAT detection, remote control, user login and multi-user management, and expanded HTTP / HTTPS / FTP download capabilities.

Current README features include BitTorrent, HTTP / HTTPS, RSS subscriptions and automatic downloads, an integrated WebUI, and network status tools. The roadmap items above are not current-release claims.
