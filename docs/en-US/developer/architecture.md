# Architecture

OpenNet is a native Windows desktop client. The README describes WinUI 3, C++/WinRT, and MVVM-related framework components as its foundation.

Major open-source dependencies include [aria2](https://github.com/aria2/aria2), [libtorrent](https://github.com/arvidn/libtorrent), [Boost.Asio](https://github.com/boostorg/asio), [Boost.Beast](https://github.com/boostorg/beast), [SQLite](https://github.com/sqlite/sqlite), [OpenNet.Server](https://github.com/Millennium-Science-Technology-R-D-Inst/OpenNet.Server), and [OpenNet.Traversal](https://github.com/Millennium-Science-Technology-R-D-Inst/OpenNet.Traversal).

Dependencies evolve; use the [source repository list](https://github.com/hoshiizumiya/OpenNet) and project files as the current reference. This page does not imply roadmap features are in the current architecture.
