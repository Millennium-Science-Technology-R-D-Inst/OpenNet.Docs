# About OpenNet

OpenNet for Windows is an open-source download client built with WinUI 3 and C++/WinRT. Source code: [hoshiizumiya/OpenNet](https://github.com/hoshiizumiya/OpenNet).

## Supported platforms

| Platform | Status |
| --- | --- |
| Windows 11 x64 | Supported |
| Windows 11 ARM64 | Supported |
| Windows 10 | Outside the support plan; it may run but compatibility is not guaranteed. |

## Current features

- BitTorrent downloads from .torrent files and magnet links.
- HTTP / HTTPS downloads.
- RSS subscriptions with rule-based automatic downloads.
- Integrated WebUI task management.
- NAT tools for checking network status.

See the [feature overview](/en-US/features/) and [roadmap](/en-US/developer/roadmap) for the boundary between current features and planned work.
