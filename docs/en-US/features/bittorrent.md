# BitTorrent downloads

OpenNet supports .torrent files and magnet links. Use the add-task entry point in your release to import a file or paste a link, review task details, then check progress, files, and available peers in the task list.

Speed depends on available peers, seed status, and network conditions. NAT tools inspect network status, but automatic traversal and DHT / PEX / LSD remain roadmap items. Download only content you are allowed to access, and check diagnostic details for private links before sharing.
