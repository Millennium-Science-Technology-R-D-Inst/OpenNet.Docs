# Task management

The task list brings together downloads created through BitTorrent, HTTP / HTTPS, and RSS rules. The project's BitTorrent preview includes a file list, speed graph, and peer information; columns and detail layouts may change between releases.

Typical flow: create a task, confirm its status in the list, and open task details to review information for that type. If it does not behave as expected, see [troubleshooting](/en-US/guide/troubleshooting). Button positions and shortcuts may change, so use the installed release as reference.
