# Feature overview

| Feature | Status | Notes |
| --- | --- | --- |
| BitTorrent | Available | .torrent files and magnet links. |
| HTTP / HTTPS | Available | File downloads over HTTP and HTTPS. |
| RSS | Available | Subscribe to feeds and add matching tasks automatically. |
| Integrated WebUI | Available | Manage tasks through the included WebUI. |
| NAT tools | Available | Check network status. |
| Automatic NAT traversal, DHT / PEX / LSD | Roadmap | See the [roadmap](/en-US/developer/roadmap). |
| Remote control and multi-user support | Roadmap | Do not assume these are available in the current release. |
