# Localization and documentation translations

OpenNet uses [Crowdin](https://crowdin.com/project/opennet/) to coordinate translations of app interface strings. Contributions and reviews are welcome.

Open the [OpenNet Crowdin project](https://crowdin.com/project/opennet/), choose a language and resource, then follow the terminology and review process shown there.

This documentation currently provides Simplified Chinese and English. Fix typos, broken links, or inconsistent terms in [OpenNet.Docs](https://github.com/Millennium-Science-Technology-R-D-Inst/OpenNet.Docs) and submit a pull request. Keep product names, APIs, library names, and protocols intact, and do not describe roadmap work as released features.
