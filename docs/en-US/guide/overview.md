# Project overview

OpenNet is a download and network management application for Windows. It is currently built with WinUI 3 and C++/WinRT, bringing task management, RSS subscriptions, an integrated WebUI experience and network status tools together in a desktop app.

## Current features

- Create BitTorrent tasks from .torrent files or magnet links.
- Manage HTTP/HTTPS download tasks.
- Subscribe to RSS feeds and automatically add tasks according to configured rules.
- Use an integrated WebUI experience to manage tasks.
- Inspect task files, peers and speed graphs.
- Check network status with NAT tools.

Automatic NAT traversal, DHT, PEX, LSD, remote control and user accounts remain roadmap items; they should not be read as shipped capabilities.

## Platform support

The project currently targets Windows 11 x64 and ARM64. Windows 10 is not in the support plan. It may run in some environments, but core functions, RPC calls or UI may have issues.
