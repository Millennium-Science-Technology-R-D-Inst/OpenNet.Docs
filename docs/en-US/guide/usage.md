# Common workflows

These workflows are based on the project's current public feature descriptions and screenshots. Button names may change by release; follow the interface in the version you are using.

## Add a download task

OpenNet supports BitTorrent torrent files and magnet links, as well as HTTP/HTTPS download tasks. Choose the matching add method in the app, then follow the task in the task list.

## Inspect task details

Open a task to inspect its files, peer information and speed graph. Peers are other clients participating in the same BitTorrent task; the peer list shows the task's current connection information.

## Use RSS subscriptions

Add an RSS feed and configure rules to automatically add matching tasks. Automatic task creation depends on your subscription rules, so review the match conditions before enabling them.

## Use the integrated WebUI

OpenNet includes an integrated WebUI management experience. The entry point and available controls depend on the version you are using.

## Check network status

Use the NAT tools to inspect network status. A status check is different from automatic NAT traversal, which remains on the project roadmap.

## Get help

When you can reproduce an issue, note your OpenNet and Windows versions, then search or report it in [OpenNet Issues](https://github.com/hoshiizumiya/OpenNet/issues).
