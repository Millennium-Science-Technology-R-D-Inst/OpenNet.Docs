# Quick start

OpenNet targets Windows 11 x64 and ARM64. Windows 10 is outside the supported platform list. Install the app from the [Microsoft Store](https://apps.microsoft.com/detail/9nhbtsz6s5z2), then add a download by source:

- .torrent file or magnet link for BitTorrent.
- HTTP / HTTPS URL for a file download.
- RSS subscription with rules that automatically add matching tasks.

Use the task list or integrated WebUI to review tasks. BitTorrent details can also show files and peers. Interface labels may change between releases, so use the version you installed.

For help, read the [FAQ](/en-US/guide/faq) and [troubleshooting guide](/en-US/guide/troubleshooting). Include app and system versions, CPU architecture, reproduction steps, and sanitized logs in an issue. Do not publish credentials or private download links.
