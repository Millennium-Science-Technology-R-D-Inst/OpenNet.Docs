## 先了解 OpenNet

OpenNet 是使用 WinUI 3 与 C++/WinRT 构建的 Windows 下载客户端，目前支持 Windows 11 x64 与 ARM64。Windows 10 不在支持范围内。

[了解项目](/project) · [查看功能指南](/features/) · [浏览源码](https://github.com/hoshiizumiya/OpenNet)
