# 项目介绍

OpenNet for Windows 是使用 WinUI 3 与 C++/WinRT 构建的开源下载客户端。源码位于 [hoshiizumiya/OpenNet](https://github.com/hoshiizumiya/OpenNet)。

## 支持平台

| 平台 | 状态 |
| --- | --- |
| Windows 11 x64 | 支持 |
| Windows 11 ARM64 | 支持 |
| Windows 10 | 不在支持计划内，可能运行但不保证兼容 |

## 当前功能

- 使用 .torrent 文件或磁力链接进行 BitTorrent 下载。
- HTTP / HTTPS 文件下载。
- RSS 订阅与按规则自动下载。
- 集成 WebUI 任务管理体验。
- NAT 网络状态工具。

查看[功能总览](/features/)及[路线图](/developer/roadmap)，区分当前功能与规划方向。
