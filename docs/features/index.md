# 功能总览

| 功能 | 状态 | 说明 |
| --- | --- | --- |
| BitTorrent | 当前支持 | .torrent 文件或磁力链接。 |
| HTTP / HTTPS | 当前支持 | HTTP 与 HTTPS 文件下载。 |
| RSS | 当前支持 | 订阅源并按规则自动添加任务。 |
| 集成 WebUI | 当前支持 | 通过集成 WebUI 管理任务。 |
| NAT 工具 | 当前支持 | 检查网络状态。 |
| 自动 NAT 穿透、DHT / PEX / LSD | 路线图 | 见[发展路线图](/developer/roadmap)。 |
| 远程控制与多用户 | 路线图 | 当前不应假设这些能力已可用。 |
