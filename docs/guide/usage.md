# 常见使用流程

下列流程依据项目当前公开的功能说明与界面预览编写。部分具体按钮名称可能随版本变化；请以应用中的实际界面为准。

## 添加下载任务

OpenNet 支持 BitTorrent 种子文件和磁力链接，也支持 HTTP/HTTPS 下载任务。根据你收到的链接或文件，在应用中选择对应的添加方式，然后在任务列表中跟踪状态。

## 查看任务信息

打开一个任务后，可以查看文件列表、对等节点信息和速度图。对等节点是参与同一 BitTorrent 任务的其他客户端；该列表用于查看当前任务的连接情况。

## 使用 RSS

添加你希望关注的 RSS 订阅源，并按应用提供的规则设置自动添加任务。自动下载行为取决于你配置的订阅规则；请先检查规则再启用。

## 使用集成 WebUI

应用包含集成 WebUI 管理体验。具体入口和可用范围以当前版本界面为准。

## 检查网络状态

使用 NAT 工具查看当前网络状态。网络状态检查不等同于自动 NAT 穿透；自动穿透能力仍在项目路线图中。

## 获取帮助

如遇到可稳定复现的问题，请先确认使用的 OpenNet 版本和 Windows 版本，再到 [OpenNet Issues](https://github.com/hoshiizumiya/OpenNet/issues) 搜索或提交问题。
