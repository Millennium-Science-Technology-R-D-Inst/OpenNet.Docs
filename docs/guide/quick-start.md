# 快速开始

OpenNet 面向 Windows 11 x64 与 ARM64，Windows 10 不在正式支持范围内。先从 [Microsoft Store](https://apps.microsoft.com/detail/9nhbtsz6s5z2)安装应用，再按来源添加下载任务：

- .torrent 文件或磁力链接：BitTorrent 下载。
- HTTP / HTTPS URL：文件下载。
- RSS 订阅：依据当前版本提供的规则自动添加任务。

使用任务列表或集成 WebUI 查看任务。BitTorrent 任务还可查看文件与对等节点信息。界面名称会随版本变化，请以实际安装版本为准。

遇到问题时查看[常见问题](/guide/faq)和[故障排查](/guide/troubleshooting)。提交 issue 时附应用与系统版本、处理器架构、复现步骤和脱敏日志；不要公开凭据或私人下载链接。
