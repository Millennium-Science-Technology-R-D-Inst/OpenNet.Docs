# 故障排查与反馈

**无法安装或启动：**确认设备运行 Windows 11，核对 x64 / ARM64 架构，在 Microsoft Store 检查更新并重启应用。Windows 10 不在支持计划内。

**HTTP 下载失败：**确认链接可访问，检查网络、代理与防火墙。如果链接需要登录、特殊请求头或验证码，是否支持取决于当前实现。不要公开访问令牌或私人 URL。

**BitTorrent 没有速度：**确认网络连接、任务状态、可用对等节点和防火墙规则。当前 NAT 工具只检查网络状态，自动 NAT 穿透仍是路线图能力。

**RSS 未添加任务：**确认订阅源可访问，并检查自动下载规则与源更新是否匹配。选项因版本而异。

提交问题到 [OpenNet Issues](https://github.com/hoshiizumiya/OpenNet/issues)，附 OpenNet 和 Windows 版本、系统架构、复现步骤、预期与实际结果，以及脱敏后的日志。不要上传密码、令牌或个人文件路径。
